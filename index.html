💻 安装指南

浏览器（Tampermonkey）

  1. 安装用户脚本管理器：
    • 推荐：Tampermonkey
  2. 基于 Chrome / Chromium 内核浏览器：
    1. 务必开启 “扩展程序” 管理中的 “开发者模式”1
    2. 务必开启 “扩展程序” 管理中脚本管理器扩展的 “允许运行用户脚本”
    3. 具体可参考 Tampermonkey 官方指引
  3. 选择安装源：
    • GitHub 源【开发版】
    • 南大镜像源【开发版】
    • GreasyFork 源【稳定版】
  4. 刷新页面后，插件即可生效
  5. 必要时，重启浏览器

🔧 本地调试

  1. 安装 Tampermonkey，并启用 “允许访问文件网址”。
  2. 下载词库文件到本地（如：D:\github-chinese\locals.js）
  3. 在脚本管理器中修改引用路径： ```js // 原始路径 // @require https://raw.githubusercontent.com/...

// 修改为 // @require file:///D:/github-chinese/locals.js ``` 1. 刷新页面生效

Important

若无效： 1. 进入 Tampermonkey 插件设置页 1. 将 通用 - 配置模式 设置为高级，进入高级设置模式 1. 找到 安全 - 允许脚本访问本地文件 并设置为 外部(@require 和 @resource)

[!TIP] 💡 温馨提示： 您可以将词库文件拖拽至浏览器地址栏，复制路径直接使用。
